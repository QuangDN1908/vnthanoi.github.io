# TECHCONSULT — Website phong cách VCC

Bộ giao diện tĩnh gồm:
- index.html
- style.css
- script.js
- images/*.svg

## Chạy local
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo repository mới.
2. Upload toàn bộ file/thư mục.
3. Vào Settings → Pages.
4. Chọn Deploy from a branch → main → /root.
5. Save.

## Chỗ cần thay đổi
- Tên công ty/logo: trong `index.html`.
- Hotline/email/địa chỉ: phần footer và topbar.
- Nội dung dịch vụ/dự án/tin tức: trong `index.html`.
- Màu chủ đạo: biến CSS `--blue`, `--cyan`, `--dark`.
- Hình ảnh: thay các file trong thư mục `images`.

Giao diện được xây dựng độc lập theo phong cách website doanh nghiệp tư vấn hiện đại, lấy cảm hứng từ cấu trúc website VCC (header/menu, giới thiệu, số liệu, dịch vụ, dự án, thành tích, tin tức, đối tác và footer).
